# Własny agent AI w n8n

Kurs dla studentów przedmiotu „Ilościowe badania informacji”. Studenci budują w n8n agenta AI, który wyszukuje artykuły naukowe w arXiv i wypisuje informacje z abstraktów. Nie trzeba programować ani płacić: wystarczy przeglądarka, darmowe konto próbne n8n i darmowy klucz Gemini.

Kurs: https://patthub.github.io/ibi_n8n/ (po włączeniu GitHub Pages)

## Zawartość

| Ścieżka | Co to jest |
| --- | --- |
| `index.html` | Strona kursu: wstęp i 10 rozdziałów ze zrzutami ekranu i zapisem postępu |
| `img/` | Zrzuty ekranu z n8n 2.48 (czerwone ramki = gdzie kliknąć) |
| `agent-arxiv-n8n.json` | Gotowy przepływ do zaimportowania w n8n (plan B dla studentów) |
| `materialy/przewodnik-prowadzacego.md` | Przewodnik dla prowadzącego: plan zajęć 90 min, prompty, testy, problemy |
| `materialy/historia-czatu.md` | Historia rozmowy z Claude, w której powstał kurs |
| `materialy/zrzuty-skrypty/` | Skrypty, którymi zrobiono zrzuty ekranu (lokalny n8n + Playwright) |
